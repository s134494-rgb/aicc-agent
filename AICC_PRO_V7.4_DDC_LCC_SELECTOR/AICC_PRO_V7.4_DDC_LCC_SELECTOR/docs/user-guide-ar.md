# دليل المستخدم

اختر صور الكتاب الواضحة وبالترتيب. بعد التحليل راجع نوع كل صفحة والنص
المستخرج والبيانات ودرجة الثقة. الأحمر يعني خطأ أو نقصًا مانعًا، والأصفر
يتطلب تحققًا. اقتراحات DDC/LCC ليست اعتمادًا نهائيًا. لا يُضاف السجل إلى
الفهرس إلا بعد الضغط على زر الاعتماد.

للبحث اكتب الموضوع أو جزءًا من العنوان أو المؤلف في المحادثة. يعرض AICC
السجلات المعتمدة الموجودة فقط، ولا يخترع كتبًا أو مواقع رفوف.
