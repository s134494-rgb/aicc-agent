# Demo script

1. Open the dashboard and show `/api/health`.
2. Upload cover, title, copyright, contents and introduction images.
3. Explain agent status, OCR evidence, ISBN validation and confidence.
4. Show that invalid ISBN creates no MARC 020 field.
5. Compare a personal author (100) with a corporate author (110).
6. Review DDC/LCC sources, alternatives, Cutter and MARC validation.
7. Correct a field, then explicitly approve the record.
8. Search with an incomplete topic request in the AICC chat.
9. Generate `/api/reports/generate` and inspect `/api/admin/audit-logs`.

The presenter should explicitly state that classification numbers remain
professional suggestions until verified against licensed institutional data.
