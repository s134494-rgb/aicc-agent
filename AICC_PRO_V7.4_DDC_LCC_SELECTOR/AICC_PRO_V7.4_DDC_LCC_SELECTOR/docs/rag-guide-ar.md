# دليل RAG

1. افتح قسم «قاعدة معرفة الوكيل RAG».
2. اكتب عنوان الوثيقة وتصنيفها ولغتها.
3. ارفع سياسة أو دليلًا موثوقًا.
4. انتظر رسالة اكتمال الفهرسة.
5. استخدم «اختبار RAG» للتأكد أن المقطع المطلوب يُسترجع.
6. اسأل الوكيل؛ سيعرض مصدر الإجابة والأدوات المستخدمة.

لا ترفع بيانات مستفيدين شخصية. اجعل كل سياسة تحمل تاريخًا وإصدارًا واضحًا
داخل نص الوثيقة. عند تغير السياسة ارفع النسخة الجديدة وميّز عنوانها بالإصدار.
